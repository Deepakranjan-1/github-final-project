# Simple Interest Calculator

A sleek, dark-themed simple interest calculator with a masculine design aesthetic. Built with vanilla HTML, CSS, and JavaScript for fast performance and easy deployment.

## Features

- **Dark Theme UI**: Professional dark interface with orange accent colors
- **Real-time Calculations**: Results update as you type
- **Animated Results**: Smooth number animations for visual appeal
- **Input Validation**: Prevents invalid entries and provides user feedback
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Clean Interface**: Minimalist design focused on functionality

## How to Use

1. **Principal Amount**: Enter the initial amount of money you're investing or borrowing
2. **Interest Rate**: Enter the annual interest rate as a percentage (e.g., 5 for 5%)
3. **Time Period**: Enter the time duration in years (supports decimals like 1.5 for 18 months)
4. **Calculate**: Click the calculate button or simply fill all fields for real-time results

## Formula

The calculator uses the standard simple interest formula:

```
Simple Interest = (Principal × Rate × Time) / 100
Total Amount = Principal + Simple Interest
```
