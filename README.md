## How to Use

1. **Principal Amount**: Enter the initial amount of money you're investing or borrowing
2. **Interest Rate**: Enter the annual interest rate as a percentage (e.g., 5 for 5%)
3. **Time Period**: Enter the time duration in years (supports decimals like 1.5 for 18 months)
4. **Calculate**: Click the calculate button or simply fill all fields for real-time results

## Formula

The calculator uses the standard simple interest formula:

```
Simple Interest = (Principal × Rate × Time) / 100
Total Amount = Principal + Simple Interest
```

## Getting Started

### Web Application
1. Clone the repository: `git clone https://github.com/[username]/github-final-project.git`
2. Open `index.html` in any modern web browser
3. Start calculating your interest returns!

### Command Line Tool
1. Make the script executable: `chmod +x simple-interest.sh`
2. Run the calculator: `./simple-interest.sh`
3. Follow the interactive prompts
